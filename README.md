# SKAROSSERIE · State of the Art in Metalwork

> Interaktive High-End-Präsentation & Digitaler Showroom für **Schäfer Karosseriebau & Blechteilemanufaktur**.

## 🚀 Features
* **10-Minuten-Vortragsmodus:** Manuelle Steuerung via Pfeiltasten, Leertaste oder Präsentations-Clicker.
* **Ambient Kiosk Loop:** Automatischer Wechsel im Kiosk-Modus (Taste `[A]`).
* **Integrierte Medien:**
  * 3D-Fotogrammetrie & CAD Class-A
  * 5-Achs-CNC-Werkzeugfräsen (lokales MP4-Video)
  * Streckziehpressen-Aufbau & Kaltverfestigung
  * Hofele G63 Coach Doors Fertigung & Fahrzeugeinsatz (Klick-Video & Live-Exponat)
  * Verbindungstechnik & KUKA-Laserschweißen
  * Hochvolt-Batteriebox als Showpiece
* **Vollbild:** Beamer-optimiert in 16:9 (Taste `[F]` / `F11`).

## 🌐 Live-View via GitHub Pages
Diese Präsentation ist vollständig statisch (HTML5 / Vanilla CSS / Vanilla JS) und kann direkt über **GitHub Pages** bereitgestellt werden.
